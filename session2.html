Session 2: Beyond the Chatbox

Stop chatting with AI and start controlling it. Today, you connect your code to the AI engine.

60 Minutes Level: Advanced Junior

Session Mission

Today, we connect your factory to the AI power grid. We will learn how to control the 'electricity' (parameters) and how to keep our 'connection' (API keys) safe.

1. The "Head Chef" Mindset

The Shift: When you use ChatGPT on a website, you are a customer eating a meal. In this incubator, you are the Head Chef. We don’t “chat” with AI. We send intentional Requests and engineer professional Responses.

Every request consumes tokens, API credits, and startup budget. As a Co-founder, your job is not just to make the AI work — your job is to make it work efficiently.

THE SECURITY RULE

We never write API keys directly inside our code. A leaked API key is like a stolen credit card. If someone gains access to it, they can burn your credits and drain your startup budget. We always store keys inside a hidden Vault file.

2. The AI Mechanics (The Three “Dials”)

Large Language Models do not “think.” They predict the next most probable token. You control that behavior using three core dials.

1. Tokens (The Currency) AI doesn’t read full words. It reads fragments of text that can include word pieces, punctuation, and even spaces. Think of a sentence like a LEGO structure. A word like “building” may become “build” + “ing”, these are Tokens

You are charged for every input token you send and every output token the AI generates. Longer prompts and longer responses increase cost. Professional engineers design prompts carefully to control token usage and protect startup budget.
2. Temperature (The Creativity Dial) The model predicts the next token based on probability. Temperature modifies how strongly the model sticks to the most likely option.

• 0.0 — The Robot Librarian: Chooses the most probable token every time. Highly predictable and structured.
• 1.0 — The Mad Scientist: Willing to explore less probable tokens. More creative, less predictable.

Higher temperature increases randomness but may reduce coherence. Lower temperature increases consistency and reliability.
3. Context Window (The Desk Space) The context window is the model’s short-term memory. Each model has a fixed maximum token limit.

Imagine writing an essay on a desk that fits only two pages. When you add a third page, the first one falls off. When the context window fills up, older tokens are removed to make space for new ones.

Engineers must design prompts carefully to stay within token limits and avoid losing important instructions.

3. The Vault Key (Secure Setup)

To communicate with the AI, you need a secret API(Application Programming Interface) Key. This key connects your code to the AI model.

🛠 Activity: Generate Your API Key

  1. Go to platform.openai.com and create an account.
  2. Open your Dashboard and navigate to API Keys.
  3. Click "Create new secret key".
  4. Name it something like AINexus_Dev.
  5. Important: Copy the key immediately. It will only be shown once and click Done.

Never screenshot it. Never upload it. Never commit it to GitHub.

Now we hide the key inside a file called .env.

🛠 Activity: Initialize the Vault

Before you begin: Make sure you are inside your AI Nexus project folder in VS Code.

  1. Activate your Virtual Environment

    Run in your terminal:
    venv\Scripts\activate (Windows)
    source venv/bin/activate (Mac/Linux)

    You should see (venv) at the beginning of your terminal line.

  2. Install the Required Libraries

    Run:

    pip install python-dotenv langchain-openai

    Wait until installation finishes without errors.

  3. Create the Vault File

    In your main project folder (same level as your Python files), create a file named: .env

    ⚠ It must be exactly .env — not .env.txt or env.

  4. Add Your API Key

    Inside the .env file, add:

    OPENAI_API_KEY=your_actual_key_here

    Replace with your real API key. Do not use quotes or add extra spaces.

  5. Protect the Vault from Git

    Add this line to your .gitignore file:

    .env

Success Check:

git status
  • ✔ If .env does NOT appear in red → Your vault is secure.
  • ❌ If .env appears in red → It is still being tracked. Run:
git rm --cached .env

Then run git status again.

4. The First Intentional Call

We are building a Startup Idea Generator. Create a file called ai_test.py.

🛠 Step-by-Step: Run Your First AI Call

  1. Create the File
    Inside your AI Nexus project folder, create a new file named: ai_test.py

  2. Copy the Code shown below
    3. ai_test.py - The AI Mixing Desk
    import os
from dotenv import load_dotenv
from langchain_openai import ChatOpenAI

# 1. Open the vault
load_dotenv()

# 2. Set the AI "Dials"
llm = ChatOpenAI(
    model="gpt-3.5-turbo",
    temperature=0.7
)

# 3. The Intentional Request
print("--- REQUESTING STARTUP IDEA ---")
response = llm.invoke(
    "Give me one weird startup idea for a 12-year-old developer."
)

# 4. Show the response content
print(f"AI Response: {response.content}")
  3. Paste the full script into ai_test.py and save the file.
  4. Activate Your Virtual Environment(You've already done that earlier in the class)
    In your terminal, run:
    venv\Scripts\activate (Windows)
    or
    source venv/bin/activate (Mac/Linux)

  5. Run the Script
    In your terminal, type: 
    python ai_test.py
  6. Observe the Output
    If everything is working, you should see:
    • --- REQUESTING STARTUP IDEA ---
    • A startup idea printed below it

✔ If you see a startup idea → Your API connection is working.
❌ If you see an API key error → Check your .env file.
❌ If you see an import error → Run pip install langchain-openai python-dotenv.

✔If you see the error "You exceeded your current quota, please check your plan", this means that your OpenAI account has no remaining API credits. But your code successfully reached the OpenAI servers.

Tool: python-dotenv This library loads your hidden .env vault and securely provides the API key to Python at runtime.
How .invoke() Works When you run this script, Python sends a request over the internet to the OpenAI API. The model processes your input, generates text, and returns a structured response (JSON). LangChain extracts the message, and response.content displays it.

⚙ Troubleshooting & FAQs

❓ "Missing API Key" Error

Make sure:

  • Your .env file is in the root project folder.
  • The variable name is written exactly as OPENAI_API_KEY.
  • There are no extra spaces around the equals sign.

If the problem continues, restart your terminal and run the script again.

❓ "ImportError" or Module Not Found

This usually means the required libraries were not installed in your virtual environment.

Run: 

pip install langchain-openai python-dotenv

Then try running python ai_test.py again.

❓ "Quota Exceeded" Error

This happens if your API key has no remaining credits.

  • Check your OpenAI dashboard for usage.
  • Confirm you are using the correct key.
  • If needed, ask your teacher to verify your account status.

Did You Know?

The word "Token" comes from the world of arcade games and coins. In AI, tokens aren't just words—they can be punctuation marks or even spaces! An average word is about 1.3 tokens. Professionals always count their tokens to keep their "Startup Budget" under control.
