# AI Startup Incubator

## Start coding (GitHub Codespaces)

1. Sign in to GitHub.
2. On this page, click **Code → Codespaces → Create codespace on main**.
3. If it asks for `OPENAI_API_KEY`, paste your OpenAI key.
4. Wait for setup to finish the first time (a few minutes). The terminal will say
   **Setup complete**.
5. In the terminal:

   ```
   source venv/bin/activate
   python torch_basics.py
   ```

Everything is already installed. You do **not** need to run `python -m venv venv`
or `pip install`.

## Something broke?

Start fresh. Your old codespace and any changes in it will be gone.

1. Go to <https://github.com/codespaces>.
2. Click **⋯** next to your codespace → **Delete**.
3. Come back here and create a new one.

Want to keep a file you changed? Right-click it in the file list → **Download** before deleting.

## Codespaces you're not using

Codespaces stop by themselves after 30 minutes of inactivity. Free accounts get a
limited number of hours each month, so close the tab when you're done.
